# i-Лаунчер (стиль iPhone) для Redmi 7A

- все приложения на страницах, листаются свайпом, внизу точки страниц
- иконки — скруглённые квадраты, подписи белые с тенью
- виджет «время и дата» на первой странице
- док внизу: телефон, сообщения, браузер, камера
- свайп вниз по экрану — поиск (как Spotlight)
- долгое нажатие на иконку — «О приложении» / «Удалить»

## Как собрать APK

### Вариант 1: Android Studio (на компьютере)
1. Установи Android Studio.
2. File → Open → папка iLauncher. Подожди Gradle Sync.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Файл: app/build/outputs/apk/debug/app-debug.apk

### Вариант 2: GitHub (без установки программ)
1. Создай репозиторий на github.com и загрузи все файлы (включая папку .github).
2. Вкладка Actions → Build APK → Run workflow.
3. Скачай app-debug.apk из Artifacts.

## Установка
1. Скопируй app-debug.apk на Redmi 7A, открой (разреши установку из неизвестных источников).
2. Нажми «Домой» → выбери «i-Лаунчер» → «Всегда».
3. Вернуть старый: Настройки → Приложения → Приложения по умолчанию → Главный экран.
